# MSS Switch Loader

Каркас homebrew UI для devkitPro/libnx. На текущем этапе loader только показывает проверяемую директорию и предупреждение fail-closed. Автоматическая установка overlay будет добавлена после hardware-smoke тестов.

```bash
# В devkitPro shell
make -C switch-loader
```

Не содержит ключей, игровых файлов или Nintendo SDK. Автор: **Dimasick-git**.
