# Contributing

1. Не прикладывайте игровые ассеты, ключи, дампы или закрытые SDK.
2. Любая compatibility-заявка обязана содержать Minecraft version, Build ID hash, Atmosphère version, модель SoC и воспроизводимый лог.
3. Новая версия получает `detected`; `verified` разрешён только после тестов на реальном железе.
4. Выполните `python -m unittest discover -s tests -v`.
5. Новые исходники должны содержать автора **Dimasick-git** в metadata/headers, где это уместно.
