# Security Policy

Сообщайте приватно о path traversal, command injection, unsafe archive extraction и утечках игровых файлов. Не публикуйте ключи или дампы в Issues. MSS никогда не запускает toolchain через shell и блокирует symlink, traversal, неизвестные поля и неподтверждённые версии.

Поддерживается только последняя ветка `main`. Автор: **Dimasick-git**.
