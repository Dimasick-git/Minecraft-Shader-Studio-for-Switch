# Руководство по установке шейдеров через LayeredFS

Для того чтобы ваши шейдеры заработали на Nintendo Switch, необходимо использовать систему **LayeredFS**, предоставляемую кастомной прошивкой **Atmosphère**.

## Структура папок

Ваши модифицированные файлы должны располагаться по следующему пути на SD-карте:
`sdmc:/atmosphere/contents/<TitleID>/romfs/renderer/materials/`

### Title ID для Minecraft на Switch
| Регион / Версия | Title ID |
| :--- | :--- |
| **Minecraft (Base Game)** | `0100ABF008968000` |
| **Minecraft Preview** | `01006A8017406000` |

## Порядок действий

1.  Убедитесь, что у вас установлена актуальная версия **Atmosphère**.
2.  Создайте папку с вашим Title ID внутри `/atmosphere/contents/`.
3.  Внутри создайте структуру `romfs/renderer/materials/`.
4.  Скопируйте ваши скомпилированные `.material.bin` файлы в эту папку.
5.  Перезапустите игру.

## Отладка и логи
Если шейдеры не загружаются:
- Проверьте логи Atmosphère в папке `/atmosphere/logs/`.
- Убедитесь, что формат `.material.bin` соответствует версии игры (используйте `mss doctor` для проверки совместимости).
- Попробуйте использовать **SimpleModManager** для удобного включения/выключения модов.
